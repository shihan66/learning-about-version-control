# Learning about Version Control
Author: Shihan Xu
Solving merge conflicts takes conscious effort, but I can do it!

What i like most about version control: is that it keeps the complete history and commits of my work to see how my work evolves, and makes collaboration much clearer and easier.

What i find most challenging about version control: is that we need to always keep highly focues on knowing how branches and merges etc. interact and always keep the discipline, or you might be easy to get confused if you don't know where those branches come from.
